학생들의 점수를 입력받아 평균 점수를 계산하고,
평균 이상 점수를 받은 학생의 이름을 출력하는 프로그램을 작성하시오.

힌트:
1. HashMap를 사용하여 학생 이름과 점수를 저장한다.
2. Scanner를 이용해 학생 수와 각 학생의 이름, 점수를 입력받는다.
3. 평균 점수를 계산한 뒤, 평균 이상을 받은 학생들의 이름을 출력한다.

#### 입력 예시 1
```
3
Alice 85
Bob 70
Charlie 90
```
#### 출력 예시 1
```
Average: 81.67
Students: Alice, Charli
```
