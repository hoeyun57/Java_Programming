while문을 이용하여 정수 여러 개를 입력 받고 평균을 출력하는 프로그램으로 요구 사항을 참고하여 작성하시오

### [요구 사항]  
입력에서 음의 정수는 모두 빼고 평균을 구한다. 제외된 숫자는 출력하고, -1이 입력되면 입력이 종료된다.  
아래의 입력 예와 출력 예를 참고하여 프로그램을 작성한다. 

#### 입력 예 1
```
100 200 300 -400 -500 -1
```
#### 출력 예 1
```
Enter integers followed by -1 at the end.
-400 Excluding
-500 Excluding
The number of integers is 3,The average is 200.0
```
#### 입력 예 2
```
-1
```
#### 출력 예 2
```
Enter integers followed by -1 at the end.
-1 Excluding
No number entered.
```
#### 입력 예 3
```
10 20 -2 30 40 -1
```
#### 출력 예 3
```
Enter integers followed by -1 at the end.
-2 Excluding
The number of integers is 4,The average is 25.0
```
