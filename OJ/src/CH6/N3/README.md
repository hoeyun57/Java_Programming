### [문제 설명]
사과의 개수와 한 박스에 담을 수 있는 사과의 최대 개수를 입력받아, 모든 사과를 담기 위해 필요한 최소한의 박스 개수를 구하는 프로그램이다.

첫 번째 입력값 x는 전체 사과의 개수를 의미하고, 두 번째 입력값 n은 한 박스에 담을 수 있는 사과의 최대 개수를 의미한다.

사과가 박스에 정확히 나누어 떨어지지 않는 경우에도 남은 사과를 담기 위해 추가 박스가 필요하므로, 계산 결과를 "올림"하여 최소 박스 개수를 구한다.

예를 들어 사과가 23개이고 한 박스에 최대 5개를 담을 수 있다면, 4개의 박스에는 20개까지만 담을 수 있으므로 총 5개의 박스가 필요하다.

### [입력]
첫 번째 줄에 전체 사과의 개수 x를 입력한다.  
두 번째 줄에 한 박스에 담을 수 있는 사과의 최대 개수 n을 입력한다.

x와 n은 양의 정수로 주어진다.

### [출력]
모든 사과를 담기 위해 필요한 최소한의 박스 개수를 출력한다.

### [입력 및 출력 예시]

#### [입력 1]
```
23
5
```
#### [출력 1]
```
5
```
#### [입력 2]
```
20
5
```
#### [출력 2]
```
4
```
#### [입력 3]
```
7
3
```
#### [출력 3]
```
3
```
