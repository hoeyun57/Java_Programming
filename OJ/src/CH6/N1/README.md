### [문제 설명]
다음 프로그램은 하나의 문자열을 입력받아 문자열의 형식을 확인한 후, 문자열에 포함된 값들을 추출하여 출력하는 프로그램이다.

입력 문자열은 다음 조건을 만족해야 한다.
- 문자열은 반드시 $로 시작해야 한다.
- 문자열은 반드시 #으로 끝나야 한다.
- $와 # 사이의 값들은 쉼표(,)로 구분된다.
- 올바른 형식의 문자열인 경우 $와 #을 제외하고, 쉼표를 기준으로 각 값을 분리하여 한 줄에 하나씩 출력한다.
- 문자열의 길이가 2보다 작거나, $로 시작하지 않거나, #으로 끝나지 않는 경우 아무것도 출력하지 않는다.

예를 들어 $1,2,3,45#가 입력되면 1, 2, 3, 45를 각각 한 줄씩 출력한다.

### [입력]
첫 번째 줄에 하나의 문자열이 주어진다.

올바른 입력의 형식은 다음과 같다.

$값1,값2,...,값N#

각 값의 문자열 길이는 서로 다를 수 있다.


### [출력]
입력 문자열이 올바른 형식이면 $와 #을 제거한 후, 쉼표(,)를 기준으로 분리한 각 값을 한 줄에 하나씩 출력한다.

입력 문자열이 올바른 형식이 아니면 아무것도 출력하지 않는다.

#### [입력 1]
```
$1,2,3,4#
```
#### [출력 1]
```
1
2
3
4
```
#### [입력 2]
```
$apple,banana,orange#
```

#### [출력 2]
```
apple
banana
orange
```
#### [입력 3]
```
1,2,3,4#
```

```
```
