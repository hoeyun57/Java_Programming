### [문제 설명]
다음 프로그램은 하나의 문자열과 변경할 특정 문자열을 입력받아, 입력된 문자열에서 해당 문자열을 찾아 대문자로 변환하여 출력하는 프로그램이다.

입력 문자열에 찾고자 하는 특정 문자열이 포함되어 있는 경우, 해당 문자열을 대문자로 변환한 전체 문자열을 출력한다.
찾고자 하는 문자열이 포함되어 있지 않은 경우에는 아무것도 출력하지 않는다.

예를 들어 "I like java programming"과 "java"가 입력되면,
"I like JAVA programming"을 출력한다.

### [입력]
첫 번째 줄에 문자열을 입력한다.  
두 번째 줄에 대문자로 변경할 특정 문자열을 입력한다.

첫 번째 줄의 문자열에는 공백이 포함될 수 있다.

### [출력]
입력 문자열에 특정 문자열이 포함되어 있으면, 해당 문자열을 대문자로 변경한 전체 문자열을 출력한다.

특정 문자열이 포함되어 있지 않으면 아무것도 출력하지 않는다.

### [입력 및 출력 예시]

#### [입력 1]
```
I like java programming
java
```
#### [출력 1]
```
I like JAVA programming
```
#### [입력 2]
```
apple banana orange
banana
```
#### [출력 2]
```
apple BANANA orange
```
#### [입력 3]
```
Java programming is fun
python
```
