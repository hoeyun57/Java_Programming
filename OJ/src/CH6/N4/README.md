### [문제 설명]
택시의 이동 거리를 입력받아 택시 요금을 계산하는 프로그램이다.

택시의 기본요금은 4,800원이며, 이동 거리 1km당 1,000원의 요금이 추가된다.  
계산된 택시 요금은 100원 단위로 반올림하여 출력한다.

예를 들어 이동 거리가 3.74km인 경우,
계산된 요금은 8,540원이며 이를 100원 단위로 반올림하면 8,500원이 된다.

### [입력]
첫 번째 줄에 택시의 이동 거리(km)를 실수로 입력한다.

### [출력]
이동 거리에 따른 택시 요금을 계산한 후, 100원 단위로 반올림한 금액만 출력한다.

### [입력 및 출력 예시]

#### [입력 1]
```
3.74
```
#### [출력 1]
```
8500
```
#### [입력 2]
```
5.0
```
#### [출력 2]
```
9800
```
